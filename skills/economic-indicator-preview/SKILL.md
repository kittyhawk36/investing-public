# 経済指標発表前の分析

CPI・雇用統計・FOMC・PCE・GDPなど、相場に影響する指標が当日または近日に発表される場合、分析の前に必ずWeb検索する。Web検索なしで判断しない。

## 確認する順序

1. 公式発表元で、発表日時と対象指標を確認する。
2. Reuters・AP・Bloomberg・公式機関などで、直近の市場が何を織り込んでいるかを確認する。
   ニュースの情報源の優先順位は、Reuters → AP → Bloomberg → CNBC → 各国政府・中央銀行・取引所の公式発表とする。Wikipedia、SNS、個人ブログは使わない。
3. 直近の米株、米10年債利回り、ドル円、該当セクターの値動きを確認する。
   数値はInvesting.com → Trading Economics → CNBCの順に、Webページを直接開いて本文で確認する。Web検索結果のスニペットの数値は使わない。
4. 指標の市場予想を確認する。CPIの場合は、ヘッドラインだけでなく、コアCPIの前年比・前月比を必ず見る。
5. 分析では、次の4点を重視する。「発表値そのもの」よりも重視すること。
   - 市場予想との差
   - すでに織り込まれていた内容
   - コア指標
   - 金利反応

## 注意

- 記事の発行日時と対象となる出来事の日付を確認し、古い情報を使わない。
- 因果関係を断定しない。見通しを述べるときは「予測です」と前置きし、確認された事実と区別する。
- 必要以上に何回も質問を繰り返さない。
