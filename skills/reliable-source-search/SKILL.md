# Reliable Source Search

Apply this before and during web research used to answer a factual, current-events, or data question for the user.

## Rules

1. **Never use Wikipedia**, under any circumstance, as a source.
2. **Only cite primary sources and reliable media**: official government/company/statistics sources, 日経, NHK, Reuters, Bloomberg, and outlets of comparable editorial standard. Do not use SEO content-farm sites, unverified blogs, or forum posts as the basis for a factual claim.
3. When choosing which search result to open or fetch, **rank by source reliability first** — never by which URL happens to be reachable, unblocked by robots.txt, or paywall-free. Accessibility is not a selection criterion.
4. **If no reliable source is reachable** (blocked, paywalled, not found), say so plainly: state that the fact could not be confirmed from a reliable source, rather than substituting a lower-reliability source silently or presenting unconfirmed information as settled fact.
5. If a claim is confirmed by only one reliable source, or only partially confirmed, say so explicitly rather than stating it with full confidence.
6. A wire-service article (e.g. 共同通信, 時事通信) republished by a regional or lesser-known outlet is acceptable to cite **only when** the original wire distributor or a top-tier outlet carrying the same wire content isn't reachable, and this substitution should be noted, not silent.
7. This applies any time information is being looked up on the user's behalf — not only when the user explicitly says "search" or "調べて."
