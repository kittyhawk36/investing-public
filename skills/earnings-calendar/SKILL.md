# earnings-calendar スキル

## トリガー
ユーザーが `/earnings-calendar`、`@earnings-calendar`、または `$earnings-calendar` と明示したときのみ実行する。

## STEP 1: 保有銘柄の取得

最初に「マネックス証券」プラグインを使用する。

1. 口座サマリーを取得する。
2. 米国株保有残高を取得する。
3. 米国株保有残高からティッカーを抽出する。

プラグインが見つからない、利用できない、またはエラーになった場合は、その事実を伝えて終了する。ブラウザ、一般Web検索、CSVなどで口座情報を代用しない。

## STEP 2: ティッカーリストの整理

同一ティッカーが複数行ある場合は重複を除き、保有中の米国株ティッカーを一覧にする。

## STEP 3: 各銘柄の決算日をWeb検索

今日の日付と1ヶ月後の日付を基準とする。

各ティッカーについて、Web検索で公式IRの決算発表予定を最初に確認する。公式発表で確認できない場合は、Nasdaq公式、Reuters、CNBC、Bloombergなどの信頼できる情報源で確認する。

```
クエリ例: "NVDA earnings date 2026"
```

Web検索結果から次回決算日を特定する。
**日付が明確に確認できない場合は「不明」とする。推測で日付を記載しない。**

Web検索では現在の年を使用する。効率化のため、複数銘柄をまとめて検索してもよい：
```
クエリ例: "GOOGL RDDT MSFT AMZN earnings date May 2026"
```

## STEP 4: フィルタリング

- 本日の日付を基準に「本日〜1ヶ月以内」の決算のみ抽出する
- 1ヶ月を超える決算は表示しない
- 決算日が不明な銘柄は別セクションに記載する

## STEP 5: 結果の表示

決算日の昇順（近い順）でソートして表示する。

```
## 📅 決算カレンダー（今後1ヶ月）
基準日: {今日の日付}〜{1ヶ月後の日付}

| 決算日 | 銘柄 | 発表タイミング | 残り日数 |
|--------|------|--------------|---------|
| 4/29（火）| GOOGL | 引け後 | 2日後 |
| 4/30（水）| RDDT  | 引け後 | 3日後 |
...

### 決算日が確認できなかった銘柄
XXX, XXX, XXX

```

**発表タイミング**は「引け後（After Close）」「寄り前（Before Open）」「不明」のいずれかを記載する。

## 注意事項

- 公式IRで確認できた日付は、その公式情報を優先する。公式情報がない場合は、信頼できる複数ソースで確認する
- 企業の決算日は変更になることがあるため、確認日を明記する
- EPS予想などの数値は本スキルのスコープ外（銘柄分析スキルで対応）
